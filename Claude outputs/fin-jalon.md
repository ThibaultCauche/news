On clôture le jalon **$ARGUMENTS**.

1. Reprends les critères d'acceptation de **$ARGUMENTS** dans `docs/04-jalons.md`. Pour chacun, vérifie-le réellement (lance les tests, les commandes, les requêtes) et dis-moi ce qui passe et ce qui ne passe pas.
2. Pour ce qui ne passe pas : propose de corriger, ou de reporter avec une raison écrite.
3. Une fois validé avec moi :
   - coche les critères et passe le statut du jalon à « Fait (date) » dans `docs/04-jalons.md` ;
   - ajoute les décisions prises pendant le jalon dans la section 7 de `docs/00-vision-feuille-de-route.md` (format `- AAAA-MM-JJ — décision`) ;
   - mets à jour « État actuel » et « Commandes » dans `CLAUDE.md` ;
   - résume en 5 lignes max ce qui a changé, pour que je le reporte dans le projet claude.ai.
4. Propose un message de commit.
